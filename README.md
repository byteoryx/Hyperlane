# HyperlaneSoft
Софт для автоматизации минта и прогона NFT по [бриджам](https://minter.merkly.com/hyperlane) проекта [Hyperlane](https://www.hyperlane.xyz/)

FAQ находится внизу этого файла!

## Основные возможности
- Подключение прокси
- Рандомизация путей прогона
- Рандомизация временных промежутков между бриджами прогона
- Параллельный запуск аккаунтов
- Возможность закончить незаконченные (по каким-то причинам) прогоны
- Автоматическое пополнение нативных монет с биржи OKX (доступна рандомизация кол-ва вывода монет)

### Просим обратить внимание!
- Не для всех сетей их списка доступен вывод нативной монеты с биржи OKX! Смотреть таблицу: (строка `OKX`).
- Дефолтное количество вывода нативных токенов (в долларах) с биржи OKX указано в таблице: (строка `Default`). Чтобы изменить данное значение, смотрите FAQ!
- Минимальное количество для вывода нативных токенов (в монете) с биржи OKX указано в таблице: (строка `Minimum`). При изменении значения `Default` убедитесь, что ваше значение (в долларах) при переводе в нативную монету не меньше значения `Minimum`!

## 🛠 Параметры софта для настройки
- `private_key`(R): приватный ключ аккаунта
- `address`: адрес прогоняемого аккаунта
- `okx_api_key`: приватный ключ OKX
- `okx_secret_key`: секретный ключ OKX
- `okx_passphrase`: парольная фраза OKX
- `proxy`: прокси аккаунта (login:password@address:port) | `пустая ячейка`: прогон без прокси
- `nft_id`: id от NFT в сети `network_mint` | `пустая ячейка`: совершить минт в сети `network_mint`
- `network_mint`(R): сеть минта NFT или сеть в которой уже находится NFT | `RANDOM`: минт в рандомной сети (из выбранных)
- `СЕТИ`(R): 1 - выбрать сеть для прогона | `пустая ячейка`: прогон без данной сети
- `max_eth_gwei`: максимальная стоимость газа в сети в gwei (работает для сетей с нативной монетой ETH) | `пустая ячейка`: стоимость газа не ограничена
- `n_txs_min`: минимальное кол-во транзакций
- `n_txs_max`: максимальное кол-во транзакций
- `random_bool`: 1 - включить рандомизацию пути | `пустая ячейка`: не использовать рандомизацию сети
- `time_sleep_min`: минимальный диапазон временной задержки между бриджами (в секундах!) | `пустая ячейка`: использовать значение по умолчанию (100)
- `time_sleep_max`: максимальный диапазон временной задержки между бриджами (в секундах!) | `пустая ячейка`: использовать значение по умолчанию (200)
- `time_sleep_start`: временная задержка перед запуском аккаунта (в секундах!) | `пустая ячейка`: использовать значение по умолчанию (0)
- `return_bool`: 1 - вернуть NFT в сеть с которой начинался прогон | `пустая ячейка`: не возвращать

Параметры со знаком (R) являются обязательными для заполнения! 

Для параметра `СЕТИ` обязательной ячейкой для заполнения является ячейка: `network_mint`

## Установка и запуск
### 🐍 Установка Python
1. Перейдите на [официальный сайт Python 3.11](https://www.python.org/downloads/release/python-3116/)
2. В разделе "Files" выберите подходящий вариант для вашей операционной системы
3. Запустите установщик и обязательно поставьте галочку "Add Python to PATH"

### 🤖 Установка софта
1. На GitHub нажмите кнопку "Code" -> "Download ZIP" и разархивируйте в выбранную папку
2. Откройте терминал и перейдите в папку с ботом: `cd "path/to/bot"`, где `path/to/bot` - путь к папке с ботом
3. Установите зависимости: `pip install -r requirements.txt`
4. Откройте файл `soft_settings.xlsx` и настройте ваши аккаунты
5. Запустите софт командой: `python main.py`
6. После проверки всех аккаунтов софт пришлет сообщение: `Software is ready to start! Do you want to start it? (yes/no)`
7. Напишите `yes`, если вы хотите запустить софт, и `no`, если нет
8. При выборе `yes` софт спросит вас: `How many retries do you want to have? (integer number)` (что такое retries можно прочитать в FAQ снизу). Введите кол-во retries и ожидайте запуска софта!

Софт закончит работу, если выведет: `HyperlaneSoft has been finished!`

> 📃 **Логирование действий софта**<br>
> Файлы с историями действий всех запусков софта сохраняются в папке: `__system__/dir_logger/storage`

### FAQ
### 1. Как сделать минт NFT, не совершая самого прогона?
Для того чтобы сделать минт NFT, не совершая самого прогона необходимо:
1. Выбрать network_mint в которой вы хотите сделать минт
2. В ячейках сетей выбрать только выбранный вами network_mint выше
3. Запустить софт

### 2. Как поменять RPC?
Для того чтобы поменять RPC необходимо:
1. Достать новый RPC, открытые RPC мы берем на сайте: [ссылка](https://chainlist.org/)
2. В папке проекта открыть файл: `dir_Hyperlane/hl_glob.py`
3. Для необходимой сети поменять параметр: `url_rpc='ваша_ссылка_на_RPC'`

### 3. Что такое retries?
Количество retries отвечает за то, сколько попыток перезапустить прогон вы хотите сделать, если прогон аккаунта закончился НЕ успешно (add: ... | Has been stopped!). Если все прогон закончился успешно, то софт завершит работу на текущем числе retries. Мы не рекомендуем ставить слишком большое число, 3-5 попыток будет достаточно, чтобы возобновить сломанный прогон или обнаружить ошибку.

### 4. Как поменять количество вывода нативных монет с OKX?
Для того чтобы поменять количество вывода нативных монет с OKX необходимо:
1. В папке проекта открыть файл: `dir_Hyperlane/hl_glob.py`
2. Для необходимой сети поменять параметр: `deposit_usd_min='ваш_минимальный_дмапазон_количества_нативной_монеты_в_долларах'`
3. Для необходимой сети поменять параметр: `deposit_usd_max='ваш_максимальный_дмапазон_количества_нативной_монеты_в_долларах'`
4. Убедиться, что что ваше максимальное значение (в долларах) при переводе в нативную монету не меньше значения `Minimum` из таблицы с сетями выше!
Для того чтобы с OKX выводилось одинаковое кол-во монет, `deposit_usd_min` и `deposit_usd_max` должны совпадать!
